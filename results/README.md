# Generated results

Default optimization outputs are written under `runs/`. Batch studies use
`runs/BASELINE/` and `runs/COMPARISON/`; catalog plots use `database_figs/`.
Post-processing reports stay with the study being processed.

An explicit `RUN_DIR` or GUI folder selection overrides the default location.
Existing results elsewhere are not moved or deleted.

Everything here except this README is ignored by Git.
